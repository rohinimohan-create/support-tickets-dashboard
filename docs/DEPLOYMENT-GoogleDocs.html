What this project is

Application

  • Stack: Node.js, Express, EJS (server.js, views/index.ejs)
  • Data: Jira REST API — CSOP project metrics, charts, open issues
  • Port: 8080 inside the container

Platform

  • Docker image → Unity Artifact Registry
  • Tessen reads docker-compose.yml and deploys to shared GKE (test / stg / prd)
  • No Kubernetes YAML required for routine deploys

Important: Local .env is NOT used in the cluster. The running pod gets config from Tessen namespace secrets and deploy flags (-E). After changing .env, run tessen namespace secrets add and redeploy.

How deployment works

Your laptop or GitHub Actions
    → docker build + push → Artifact Registry
    → tessen deployment up → Tessen / GKE (ingress, TLS, secrets, pods)
ScriptPurpose
scripts/build-and-push.shBuild linux/amd64 image and push to registry
scripts/tessen-deploy.shRun tessen deployment up + status

Common mistake: Running deploy without push → ImagePullBackOff because :local does not exist in the registry.

First-time setup

1. Clone

git clone https://github.com/rohinimohan-create/support-tickets-dashboard.git
cd support-tickets-dashboard

2. Local .env (never commit)

cp .env.example .env
PORT=8080
JIRA_BASE_URL=https://jira.unity3d.com
PROJECT_KEY=CSOP
AUTH_MODE=bearer
JIRA_API_TOKEN=<your-jira-pat>

3. Docker auth

tessen docker config

Jira authentication

Unity Jira does not allow Basic auth (email + token). Use AUTH_MODE=bearer with a Personal Access Token.

Add secrets to Tessen

Format must be KEY=VALUE (no interactive prompt):

tessen -k test namespace secrets add \
  AUTH_MODE=bearer \
  JIRA_API_TOKEN='<your-pat>'

Or from .env:

grep -E '^(JIRA_API_TOKEN|AUTH_MODE|JIRA_BASE_URL|PROJECT_KEY)=' .env > .env.tessen
tessen -k test namespace secrets add --from-file .env.tessen
rm .env.tessen
tessen -k test namespace secrets list

Deploy to test (step by step)

Step 1 — Docker config

tessen docker config

Step 2 — Build and push (required)

bash scripts/build-and-push.sh

Must see pushed and digest sha256:...

Step 3 — Deploy

CLUSTER=test bash scripts/tessen-deploy.sh

Look for: ok Secret csops-ops-csops-tickets-test-dashboard-tessen-env

Step 4 — Status

tessen -k test status

Wait for READY 1/1

Step 5 — Verify

curl -sS "https://support-tickets-dashboard.test.app.tessen.unity.com/healthz"
curl -sS "https://support-tickets-dashboard.test.app.tessen.unity.com/api/data" | head -c 200

Expect JSON with "version": not "error":

Step 6 — Open dashboard

https://support-tickets-dashboard.test.app.tessen.unity.com (Cmd+Shift+R to refresh)

Troubleshooting

command not found: npm

Fix: Use bash scripts/build-and-push.sh — npm runs inside Docker.

unable to parse secrets arguments

Fix: Use KEY=VALUE: tessen -k test namespace secrets add JIRA_API_TOKEN='...'

ErrImagePull / ImagePullBackOff / not found :local

Fix: Run build-and-push.sh until image is pushed, then redeploy.

/api/data returns 500

Fix: curl /api/data, tessen -k test logs, fix secrets, redeploy.

JIRA_EMAIL required for basic auth

Fix: Use AUTH_MODE=bearer (Unity Jira disables basic).

403 Basic Authentication has been disabled

Fix: AUTH_MODE=bearer + PAT, redeploy with -E AUTH_MODE=bearer

Unexpected token '<' / DOCTYPE not valid JSON

Fix: Invalid PAT or bearer not set; rebuild, push, redeploy.

Secret values are never returned by the API

Fix: Normal — redeploy after adding secrets.

Security

  • Never commit .env or share PATs
  • Rotate PAT if exposed
  • Internal confidentiality on Tessen
